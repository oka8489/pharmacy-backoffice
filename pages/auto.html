Phase 4：日常業務をマニュアル化・自動化

レセコンとAIを接続。処方箋を受けてからのレセコン作業をAIが行う。

目標：事務員3人→1人体制。薬剤師は対人業務に集中。

レセコン作業の代替フロー

Step作業現在（人が行う）Phase 4（AIが行う）
①レセコン入力事務員が処方箋を見てレセコンに手入力処方箋QRコード/OCR→NSIPS CSV→レセコンへ自動入力（Computer USE）
②加算を選択事務員・薬剤師が算定可能な加算を判断して手動選択AIが患者情報・処方内容から算定可能な加算を自動判定・選択。取り漏れゼロ。
③分包機・電子薬歴へ連携レセコンから手動で連携操作NSIPS経由で分包機・電子薬歴へ自動連携
④印刷処方箋控え・お薬説明書・報酬明細・薬袋・お薬手帳シールを個別に印刷操作AIが一括印刷指示。印刷完了を自動確認。
⑤目視確認処方箋と調剤内容の照合を薬剤師が行うAIが事前チェック済み。薬剤師は確認・承認のみ。

NSIPS（薬局間データ連携）によるAPI連携

エリシア（レセコン）はNSIPS対応。CSVファイルでデータを入出力でき、AIとの連携基盤になる。

ファイル例：SIPS1/RX2026032600013000000000000001.csv

// 1: バージョンレコード（薬局情報）

// 2: 患者レコード

// 3: 処方レコード（医療機関・医師・診療科）
3,01,,,"13","2026-03-26","1","131010","大分中央病院","12345678","山田 一郎","01","内科",,

// 11: 薬品レコード（コード・薬品名・用量・回数・日数・用法）
11,01,01,"4","1234567890123","アムロジピン錠5mg「XX」","5","mg","1","1","28","1","毎食後",,
11,01,02,"4","9876543210123","メトホルミン塩酸塩錠250mg","250","mg","3","3","28","1","毎食後",,

// 9: エンドレコード
9,01,,
先頭番号レコード種別主な内容
1バージョン薬局名・電話番号
2患者患者ID・氏名・生年月日・性別・住所・電話番号
3処方受付番号・処方日・保険番号・医療機関・医師・診療科

9エンドファイル終端
連携フロー：処方箋QRコード → NSIPS CSV生成 → AIがCSVを読み取り → レセコンへ自動入力 + 分包機・薬歴へ連携 → 印刷指示
